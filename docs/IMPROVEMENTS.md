## فایل‌ها

- `modules/` — ۱۱ قطعهٔ مستقلِ Pine v5 برای درج در اندیکاتور اصلی شما
  (ترتیب و وابستگی‌ها در `modules/00_INDEX.md`)
- `src/SMC_NTS_Pro.pine` — یک اندیکاتور کامل و قابل اجرا شامل هسته پایه + همه ۹ بهبود
- `tools/check_pine.py` — بررسی‌کننده سبک (نیم‌فاصلهٔ مخفی، توازن پرانتز،
  کلمات چسبیده، بازنویسی ورودی)

## زنجیرهٔ مقداردهیِ `ntsPeriod` (مهم‌ترین نکتهٔ ادغام)

```
M01  ntsPeriod = وزن‌دهی بین حالت تریدینگ و تایم‌فریم پایه   →  simple int
 │
M03  ntsPeriod := تنظیم بر اساس رژیم (Chop / Trend)          →  series int ⚠
 │
M09b ntsPeriodFinal = در صورت فعال‌بودن Auto-Tune بازنویسی می‌شود
 │
 ▼
هسته NTS (باید با «هموارسازی دستی» ATR باشد، نه ta.atr/ta.rma)
```

## سه مانع فنی که هنگام ادغام با کد پایهٔ شما باید حل شود

1. **`simple int` در برابر `series int`**
   بعد از M03 دورهٔ NTS دیگر ثابت نیست، پس `ta.atr(ntsPeriod)` / `ta.rma(x, ntsPeriod)`
   کامپایل نمی‌شود. راه‌حل در انتهای `modules/03_adx_atr_regime.pine` آمده است.

2. **بازنویسی ورودی‌ها ممنوع است**
   `xauMinAtrPct := autoMinAtrPct` خطا می‌دهد (M09). از `xauMinAtrPctEff` استفاده شد.

3. **ترتیب تعریف متغیرها**
   M06 به `inDailyDiscount` / `inDailyPremium` / `ntsVolBoost` نیاز دارد،
   پس M07a باید «قبل از» M06 درج شود (برخلاف شماره‌گذاری ظاهری).

## اصلاحاتِ منطقی اعمال‌شده (فراتر از رفع خطای نحو)

- **M04:** عبارت `xauVolOk` در متن اولیه سه شرط با `or` داشت که شرط سوم،
  دو شرط اول را خنثی می‌کرد. معادلِ هدف، بدون عبارت تکراری نوشته شد.
- **M09a:** بررسی کریپتو باید پیش از بررسی `USD` باشد، وگرنه `BTCUSD`
  به عنوان forex شناسایی می‌شود.
- **M07b:** فیلتر Premium/Discount به یک سوییچ (`useDailyZoneFilter`) مجهز شد
  چون این فیلتر به‌تنهایی می‌تواند تعداد سیگنال‌ها را به‌شدت کاهش دهد.

## کاراکترهای نامرئی (ZWNJ)

متن ارسالی شما حاوی نیم‌فاصله (U+200C) در میان اعداد بود (مثل `‌12`).
این کاراکتر در ویرایشگر Pine دیده نمی‌شود ولی باعث خطای کامپایل می‌گردد.
`tools/check_pine.py` آن را شناسایی می‌کند:

```bash
python3 tools/check_pine.py modules/     # خروجی مورد انتظار: OK
python3 tools/check_pine.py tools/testdata/original_snippets_BAD.pine   # نمایش خطاها
```
